# 日本國物語　第一弾「薩摩の焔」

〜西郷と大久保、二つの星を見た少年の記録〜

幕末から明治の鹿児島を舞台にした、史実ベースのドットRPGです。
加治屋町の下級武士の少年・日高新八（架空の人物）の目を通して、西郷隆盛と大久保利通の出会いから別れまでを描きます。

- 画像ファイルを使わず、ドット絵はすべてコードで描いています（全体で約120KB）
- ブラウザだけで動きます。`kagoshima/index.html` をダブルクリックすれば遊べます
- スマホでは画面下に十字キーとボタンが出ます

## 史実と創作について

- **史実**：郷中教育、示現流、島津斉彬の死、西郷と月照の入水（1858年）、西郷の奄美大島行き（菊池源吾）、寺田屋事件、生麦事件、薩英戦争（7隻のイギリス艦隊、蒸気船3隻の拿捕と焼却、天保山砲台、旗艦ユーリアラス号の艦長・副長の戦死、集成館の焼失、城下の焼失）、東郷平八郎の参戦、薩摩藩英国留学生
- **創作**：主人公・新八、仙吉、母、高見馬場の郷中の若衆、セリフの細部
- **ゲーム上の脚色**：薩英戦争でイギリス兵が浜に上陸して戦う場面（実際には上陸戦はありませんでした）
