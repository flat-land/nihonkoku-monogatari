# 日本國物語

47都道府県の史実をもとにした、ドットRPGのシリーズです。

**▶ 遊ぶ：https://flat-land.github.io/nihonkoku-monogatari/**

## 第一弾　鹿児島県「薩摩の焔 〜二つの星を見た少年〜」

幕末から明治の鹿児島が舞台です。加治屋町の少年・日高新八（架空の人物）の目を通して、西郷隆盛と大久保利通の出会いから別れまでを描きます。

- 序章＋全十二章＋終章。第八章の分かれ道で、西南戦争を**薩軍**として戦うか、**政府軍**として戦うかを選びます
- 結末は4つあります。選んだ側と、新八の心（情と理）、仙吉との絆によって変わります
- ドット絵・BGM・効果音は、画像や音声のファイルを使わず、すべてコードで描いて鳴らしています
- スマホ（縦向き・横向き）とパソコンの両方で遊べます

### 主な仕組み

| 仕組み | 内容 |
|---|---|
| 合戦 | 軍と軍の戦い。「兵力」と「士気」を削り合い、一度だけ使える「策」がある（薩英戦争・禁門の変・鳥羽伏見・鶴ヶ城・熊本城・田原坂・城山） |
| 示現流 | 「チェスト」は戦いの最初のターンだけ威力2倍（二の太刀要らず） |
| 詮議 | 郷中の問答。答えが新八の「心」（情と理）に残り、結末に関わる |
| 立木打ち | タイミングよくAを押す、稽古場の遊び |
| 敵側の幕間 | イギリス艦隊、長州、新選組、篤姫と勝海舟、会津の八重、政府軍などの視点の短い場面 |
| 図鑑 | 人物・年表・ゆかりの地（実在の場所）・全国のつながり・結末 |
| 言葉 | 鹿児島弁／標準語／鹿児島弁＋訳 を設定で切り替え |
| 珍しい敵 | 逃げ足の速い「薩摩飛脚」や、お金を落とす「抜け荷商人」など |
| 仲間の入れ替え | 連れて行けるのは4人まで。ほかの仲間は控えに回り、道場・宿・茶屋・陣・母の家で入れ替えられる（控えも経験値を半分もらう） |
| その他 | 家に入れる、蔵の鍵、馬に乗る、ミニマップと地図、会話ログ、オート、3倍速・5倍速、回転ロック中でも横向きで遊べる設定 |

### 史実と創作について

- 登場人物の多くは実在の人物で、出来事は史実をもとにしています（年月はおおむね旧暦）
- **創作**：主人公の新八、仙吉、母、高見馬場の大将とその仲間、セリフの細部、薩英戦争での上陸戦、敵としての「どんどん焼け」「廃刀令」などの表現
- **脚色**：西郷の犬ツンの登場時期（上野の西郷像の犬のモデルとされる）、新八が歴史の場面に立ち会うこと
- 図鑑の「ゆかりの地」は実在の場所です。訪れるときは最新の公開情報を確かめてください

## シリーズのつながり

すべての作品を同じサイト（`flat-land.github.io/nihonkoku-monogatari/`）に置くので、ブラウザの保存領域 `nihonkoku-series` を作品どうしで共有できます。

- 各作品は、出会った人物・出来事の「県」を `links` として書きこみます
- トップページと各作品は、それを読んで「この県とはつながりがある」と表示します
- 別の県の作品で同じ人物（例：龍馬＝高知県、勝海舟＝東京都、山本八重＝福島県）が再登場したとき、前の作品での出会いを反映できます

```
index.html                シリーズの入口（47都道府県）
kagoshima/index.html      薩摩の焔
kagoshima/src/audio.js    効果音とBGM（その場で合成）
kagoshima/src/gfx.js      ドット絵（地形・人物・顔・敵・背景）
kagoshima/src/data.js     人物・能力・わざ・道具・敵・図鑑
kagoshima/src/engine.js   移動・会話・メニュー・戦闘・合戦・セーブ
kagoshima/src/story.js    序章〜第六章
kagoshima/src/story2.js   第七章〜終章・結末
kagoshima/src/maps.js     マップ
```
